# Portafolio React

Estructura base creada a partir de `portafolio.jsx`.

## Estructura

```txt
src/
  App.jsx
  main.jsx
  index.css
  components/
  data/
  hooks/
public/
```

## Ejecutar

```bash
npm install
npm run dev
```

## Notas

- El portafolio original quedó en `src/App.jsx`.
- Las carpetas `components`, `data` y `hooks` ya están creadas para seguir separando el proyecto.
