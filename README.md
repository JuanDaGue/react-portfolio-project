# Portafolio React

Portafolio personal construido con React y Vite.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Preparado para Vercel

Este proyecto ya incluye `vercel.json` para deploy desde GitHub.

Configuración esperada en Vercel:

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## Deploy desde GitHub

1. Sube este proyecto a un repositorio en GitHub.
2. Entra a Vercel y elige `Add New Project`.
3. Importa el repositorio.
4. Deja la configuración detectada por Vercel o usa los valores de arriba.
5. Haz deploy.
